# Projeto: Filtragem de Notas de Alunos com Python

Este repositório contém um script desenvolvido para a disciplina de programação, com o objetivo de filtrar alunos aprovados com base em uma nota de corte.

## Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Conceitos Praticados:** Estruturas de dados (Dicionários e Listas), laços de repetição (`for`) e estruturas condicionais (`if`).

## Como Executar o Script
1. Certifique-se de ter o **Python 3** instalado em seu computador.
2. Baixe ou clone este repositório para a sua máquina.
3. No terminal ou prompt de comando, acesse a pasta do projeto e execute o arquivo:
```bash
python script.py
```
